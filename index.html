How to use the ACBuy spreadsheet

  1. Find the seller link. Open a HipobuyFind item and locate its original marketplace URL. Paste that URL into the agent you intend to use and confirm that it accepts the listing before paying.
  2. Compare the actual measurements. For a hoodie, check chest width and body length against a garment you own. For shoes, compare the seller’s size chart using your measured foot length.
  3. Review quality-control photos. If your agent provides warehouse photos, compare the received color and size label with the selected variant. Check the return window before approving international shipment.
  4. Estimate the delivered cost. Add the product price, domestic delivery, agent fees, international delivery and any applicable taxes or duties. If a shipping line uses volumetric weight, compare quotes with and without bulky packaging.

Frequently asked questions

Can I paste a HipobuyFind product page into ACBuy?

Use the original marketplace link shown on the HipobuyFind listing. Confirm that ACBuy can load the listing and order your size and color before paying.

Which price should I use to compare two listings?

Start with the current price for the same size and color, then add domestic shipping. If you plan to ship internationally, compare parcel quotes using the same destination and packaging assumptions.
